# Healthcare Management System (OOP Project)

Welcome to the **Healthcare Management System**, a comprehensive object-oriented programming (OOP) project developed in C++. This project demonstrates core OOP principles such as abstraction, inheritance, polymorphism, operator overloading, and more. The system is designed to emulate the functionality of a basic healthcare management system, providing a structured and modular way to handle patient records, appointments, and medical staff data.

## Features

- **Abstraction**: Key functionalities are encapsulated within classes to provide a clear and modular design.
- **Inheritance**: Hierarchies are implemented to allow derived classes to inherit common behaviors from base classes.
- **Polymorphism**: Methods and operators exhibit polymorphic behavior, enabling flexible and reusable code.
- **Operator Overloading**: Custom operators have been implemented to handle operations specific to the healthcare domain.
- **Modular Design**: The project is divided into multiple `.h` and `.cpp` files, promoting separation of concerns and code reusability.
- **Scalability**: Designed with scalability in mind, allowing future enhancements and additions.

## Functionalities

The system provides:

- **Patient Management**:
  - Add, update, and delete patient records.
  - View detailed patient information.

- **Appointment Scheduling**:
  - Schedule and manage appointments.
  - Maintain a log of past and upcoming appointments.

- **Staff Management**:
  - Manage medical staff details, including doctors and nurses.
  - Assign staff to specific patients or tasks.

- **Billing System**:
  - Generate and manage bills for treatments and services.
  - Provide detailed cost breakdowns.
